# books

読書の質を上げるためのナレッジリポジトリ。

## 考え方

本は **体系（抽象）** と **本文（具体）** でできている。
具体だけを読み続けても全体像はつかめない。それは具体を受け取るだけで、抽象へ体系化していないから。

優秀なコンサルタントのように、**先に体系を大枠でつかんで構造化し、そのあと具体で枝葉を埋めていく** 読み方をする。

## 流れ

```
① 読む前   書名を伝えて Claude に「体系マップ」を作ってもらう（抽象）
           目次や内容は Claude がネットから取る
② 読む前   体系マップを読んで、全体の骨格と「読みながら確かめる問い」を頭に入れる
③ 読む     本文（具体）を読み、骨格のどこに当たるかを意識する
④ 読んだ後 余裕があれば、章ごとに枝葉をアウトプットする → Claude と一緒に整理
⑤ 読了     読む前の骨格と読んだ後の理解の差分を振り返る
```

## ディレクトリ

```
books/
  <書名>/
    00_体系マップ.html … 読む前の骨格＋枝葉（Claude が作り、枝葉を足していく）
    01_枝葉ノート.md   … 章ごとのアウトプット（自分が書き、Claude が整理を手伝う）
    02_読了まとめ.md   … 読み終えた後の振り返り
_template/            … 各ファイルの構成テンプレート（体系マップは .md の構成を .html で作る）
```
